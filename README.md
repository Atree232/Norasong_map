# のらきゃソングマップ

のらきゃっとさんの楽曲を D3.js を用いてネットワーク図として可視化したツールです。
楽曲のテーマや関連性を直感的に探索できます。

## 公開ページ
[こちらからマップを表示できます](https://atree232.github.io/Norasong_map/)

## 特徴
- **インタラクティブな操作:** ノード（円）をドラッグして動かしたり、詳細を確認したりできます。
- **フィルタリング:** 右側のパネルから、特定のテーマやカテゴリーに絞り込んで表示可能です。
- **関係性の可視化:** 楽曲同士のつながりを視覚的に把握できます。

## 使い方
1. 公開ページにアクセスします。
2. 右側のサイドバーで、興味のあるキーワードを選択してチェックを入れます。
3. マップ上のノードをクリックすると、楽曲のつながりが強調されます。
